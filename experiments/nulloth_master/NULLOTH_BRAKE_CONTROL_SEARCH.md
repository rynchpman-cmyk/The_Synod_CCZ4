Status: **observed inside the declared periodic discovery box**

## Finding

The Synod asked for the least resolved growing-mode seed that would reduce the
carrier kinetic response by two percent at the registered horizon. We did not
command the carrier to slow. We varied one permitted initial scalar amplitude,
solved the constraints anew for every trial, and let the complete production
system answer.

The first passing bracket is:

```text

first passing amplitude      0.010250
bracket width                0.000125
passing suppression          0.0207808
seed coordinate energy       0.000489821

```

This is approximately half the amplitude used by the original promotion
campaign. It is not yet a universal minimum. It is the least passing seed
resolved by this registered traversal at eight points, through time two, for
this carrier profile and this objective.

## The two denials of coincidence

The no-command branch retained canonical Nulloth and received no scalar seed.
Its scalar amplitude remained exactly zero.

The scalar-coupling-free branch received the selected scalar profile and the
same growing-mode momentum, but the three scalarization couplings were set to
zero. Its relative response was `-3.2287e-6`: a minute enhancement, not a
brake. The coupling-attributed suppression was therefore `0.0207840`, and the
canonical active branch beat the coupling-free branch.

Thus the selected response is not purchased merely by scalar stress, altered
initial geometry, or the optimizer's choice of amplitude. It enters through
the canonical scalarization couplings.

## Reservation

The response curve steepens sharply inside the final bracket: `0.010125`
fails at `1.50%`, while `0.010250` passes at `2.08%`. We therefore record a
resolved threshold bracket, not a smooth derivative or proof of global
minimality. Spatial and temporal convergence, robustness to errors, finite
geometry, actuator bandwidth, and a minimal time-dependent preparation
trajectory remain to be established before this economy can amend the
canonical spell protocol.
